# Iceberg Workspaces

The user portal at http://localhost:3002. Team members sign in with Keycloak, pick a team and environment, and work with their databases in shared [marimo](https://marimo.io/) notebooks.

Its documentation is on the documentation site: the [user portal](https://sanderdw.github.io/iceberg-data-platform/user-portal/), [notebooks](https://sanderdw.github.io/iceberg-data-platform/notebooks/), [semantic models](https://sanderdw.github.io/iceberg-data-platform/semantic-models/), [data shares](https://sanderdw.github.io/iceberg-data-platform/data-shares/), [connect from your computer](https://sanderdw.github.io/iceberg-data-platform/connect/), [AI agents](https://sanderdw.github.io/iceberg-data-platform/ai-agents/) and [configuration](https://sanderdw.github.io/iceberg-data-platform/configuration/). To build it from a checkout, see [run from source](https://sanderdw.github.io/iceberg-data-platform/develop/run-from-source/).
