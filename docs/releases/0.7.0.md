# Iceberg Data Platform 0.7.0

Release date: 2026-10-01

## Changes

- **Extensions and the Extension Bridge.** Separately released extensions add capabilities without changing the core. They use the platform only through the Extension Bridge contract 0.1.0: the signed-in user's teams and databases, and service accounts per team and environment that only team administrators enable, with one-hour catalog tokens. Extensions never receive secrets or storage keys. See [extensions](../extensions.md).
- **Conversational BI 0.1.0**, the first extension, is released alongside: ask questions about your teams' semantic models and the ones shared with your teams, in a chat with generative UI. Answers are governed queries compiled from the model, with the SQL, join path and metric definitions next to every chart. Choose OpenAI, Anthropic, Google Gemini or Amazon Bedrock.
- **The installer can add Conversational BI.** It asks in a terminal, or takes `LLM_MODEL` and the provider's key from the environment. See [installation](../install.md#add-conversational-bi).
- **Team shares reach extensions.** Shares a team received reach the read-only service account of an extension that team enabled in the same environment, never the write role.
- **Where a table comes from:** the catalog shows a table's description and, for tables a pipeline describes with the Bridge table-property conventions, a **Produced by** card with the last run, revision, test outcome and upstream tables.
- Platform administrators see and revoke extension service accounts on the Teams page, and through the MCP tools `list_automation_principals` and `revoke_automation_principal`.
- A semantic model in the catalog links to **Ask in Conversational BI** when that extension is registered.
- `scripts.flights_seed` publishes the flights data product in a partner team and shares it with a team, for demos.

See the [changelog](../../CHANGELOG.md) for details.

## Install this version

Linux / macOS:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.7.0/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.7.0/install.ps1 | iex
```

The installers pin the installation bundle and all application images to `0.7.0`, and
Conversational BI to `0.1.0`. Docker with Compose is required. The release workflow builds
images for Linux AMD64 and ARM64.
