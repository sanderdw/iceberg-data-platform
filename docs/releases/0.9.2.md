# Iceberg Data Platform 0.9.2

Release date: 2026-10-14

## Changes

- **OpenMetadata extension 0.1.1** has its own installer. One command adds it to an installed platform, in `extensions/openmetadata`: it registers the extension, asks for your OpenMetadata address and bot token, and starts it. `--demo` also starts a local OpenMetadata. See [OpenMetadata](../openmetadata.md#install).
- **Conversational BI 0.1.2** supports Gemini 4 Argon (`LLM_MODEL=google:gemini-4-argon`) and waits up to 20 minutes for Google models, so long answers are not cut off.

See the [changelog](../changelog.md) for details.

## Install this version

Linux / macOS:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.2/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.2/install.ps1 | iex
```

The installers pin the installation bundle and all application images to `0.9.2`, Conversational
BI to `0.1.2`, the dbt extension to `0.1.0` and Ingestion (dlt) to `0.1.0`. In a terminal the
installer asks which extensions to add; `ICEBERG_EXTENSIONS=conversationalbi,dbt,ingestion` adds
all three without questions. OpenMetadata has its own installer:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/openmetadata-v0.1.1/install.sh | sh
```

Docker with Compose is required. The release workflow builds images for Linux AMD64 and ARM64.
