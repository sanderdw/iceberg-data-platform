# Iceberg Data Platform 0.9.11

Release date: 2026-11-08

## Changes

- **Evaluations**, a new extension: question sets with known answers for Conversational BI, scored runs, comparisons between runs and LLMs, a measurement of what a semantic model adds, schedules, and a live check of real conversations for teams that opt in. Results land as Iceberg tables with a semantic model in the team's own database. See [Evaluations](../evaluations.md).
- **Send logs and traces to OpenTelemetry.** Set `OTEL_EXPORTER_OTLP_ENDPOINT` (`otel.endpoint` on Kubernetes) and the portals, the Bridge, the monitor, Polaris and the extensions send them to your Collector, Grafana, Elastic, Logfire or any other OTLP backend. Off by default. See [Send logs and traces to OpenTelemetry](../observability.md).
- **Extension Bridge contract 0.1.3**, with the `team-extensions` capability: one extension serves another for a team only where a team administrator enabled both.

See the [changelog](../changelog.md) for details.

## Install this version

Linux / macOS:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.11/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.11/install.ps1 | iex
```

The installers pin the installation bundle and all application images to `0.9.11`, Conversational
BI to `0.1.5`, the dbt extension to `0.1.3`, Ingestion (dlt) to `0.1.3` and Evaluations to `0.1.0`.
In a terminal the installer asks which extensions to add; `ICEBERG_EXTENSIONS=conversationalbi,dbt,ingestion,evaluations`
adds all four without questions. OpenMetadata has its own installer:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/openmetadata-v0.1.3/install.sh | sh
```

The installers need Docker with Compose. The release workflow builds images for Linux AMD64 and ARM64.

On Kubernetes, install the charts of this version:

```bash
helm install iceberg oci://ghcr.io/sanderdw/charts/iceberg-data-platform --version 0.9.11 -n iceberg \
  --create-namespace --set baseDomain=data.example.com --set tls.clusterIssuer=letsencrypt-prod --wait --timeout 15m
```

The extension charts are `iceberg-conversationalbi` 0.1.5, `iceberg-dbt` 0.1.3, `iceberg-ingestion` 0.1.3 and
`iceberg-evaluations` 0.1.0; see [add extensions](../install-kubernetes.md#add-extensions).
