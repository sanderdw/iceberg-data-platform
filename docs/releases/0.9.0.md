# Iceberg Data Platform 0.9.0

Release date: 2026-10-12

## Changes

- **Ingestion (dlt)**, the third extension: load REST APIs, PostgreSQL and MySQL or MariaDB tables, and CSV, JSONL or Parquet files over HTTPS or S3 into your team's databases with declarative [dlt](https://dlthub.com/docs) pipelines, on demand or on a schedule. A page, an API and an MCP server offer the same actions. Team administrators enable it per environment, create pipelines and set their secrets, which are encrypted and write-only; writers start runs. Each run is an isolated container that writes as the team's service account, and tables keep their identity across runs, so data shares and semantic models keep working. Loaded tables show **Produced by dlt** in the catalog, and the user portal links to the extension as **Ingestion (dlt)**. It is installed from its folder; see [installation](../install.md#add-ingestion-dlt).
- **Load data with dlt in a notebook.** The new example 08 loads paged API data into `raw_dlt_demo` with your own identity, splits nested lists into child tables and merges on a key, so a rerun adds no duplicates. `user_portal.notebook.connection` gains `dlt_destination()` for your own dlt pipelines, and the notebook image includes dlt 1.31 with its usage statistics switched off.
- The user portal's MCP server and `AGENTS.md` point agents to the Ingestion extension for loading outside data when it is installed.

See the [changelog](../../CHANGELOG.md) for details.

## Install this version

Linux / macOS:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.0/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.0/install.ps1 | iex
```

The installers pin the installation bundle and all application images to `0.9.0`,
Conversational BI to `0.1.0` and the dbt extension to `0.1.0`. Ingestion (dlt) `0.1.0` is not in
the installer yet; install it from `extensions/ingestion` (see
[Add Ingestion (dlt)](../install.md#add-ingestion-dlt)). Docker with Compose is required.
The release workflow builds images for Linux AMD64 and ARM64.
