# Iceberg Data Platform 0.9.12

Release date: 2026-11-18

## Changes

- **Maintenance**, a new extension (beta): keeps your tables in shape. It shows each table's health (snapshots, small files, delete files, manifests), and applies a policy per database on a schedule or on demand: it expires old snapshots, compacts small files and applies their deletes, removes dangling delete files, merges manifests and removes orphan files. Branch and tag heads and the table properties `history.expire.*` always win, and dry runs show what a policy would do. Its runner is built on Apache iceberg-go. The installer adds it, and on Kubernetes it has its own chart. See [Maintenance](../maintenance.md).
- Updated dependencies, including FastAPI 0.162.4 and uv 0.13.8, in the platform and every extension.

See the [changelog](../changelog.md) for details.

## Install this version

Linux / macOS:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.12/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.12/install.ps1 | iex
```

The installers pin the installation bundle and all application images to `0.9.12`, Conversational
BI to `0.1.6`, the dbt extension to `0.1.4`, Ingestion (dlt) to `0.1.4`, Maintenance to `0.0.1` and
Evaluations to `0.1.1`. In a terminal the installer asks which extensions to add;
`ICEBERG_EXTENSIONS=conversationalbi,dbt,ingestion,maintenance,evaluations` adds all five without
questions. OpenMetadata has its own installer:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/openmetadata-v0.1.4/install.sh | sh
```

The installers need Docker with Compose. The release workflow builds images for Linux AMD64 and ARM64.

On Kubernetes, install the charts of this version:

```bash
helm install iceberg oci://ghcr.io/sanderdw/charts/iceberg-data-platform --version 0.9.12 -n iceberg \
  --create-namespace --set baseDomain=data.example.com --set tls.clusterIssuer=letsencrypt-prod --wait --timeout 15m
```

The extension charts are `iceberg-conversationalbi` 0.1.6, `iceberg-dbt` 0.1.4, `iceberg-ingestion` 0.1.4,
`iceberg-maintenance` 0.0.1 and `iceberg-evaluations` 0.1.1; see [add extensions](../install-kubernetes.md#add-extensions).
