# Iceberg Data Platform 0.9.9

Release date: 2026-10-17

## Changes

- **Install on Kubernetes.** A Helm chart runs the platform, and each extension has its own chart. Every portal gets its own HTTPS host with cert-manager, notebooks run as pods and dbt and Ingestion runs as Jobs, each in a namespace of their own, behind NetworkPolicies. Polaris and Keycloak can use a managed PostgreSQL, and Polaris can run from the official Apache Polaris chart. The `kubernetes-install` agent skill does it with you. See [Install on Kubernetes](../install-kubernetes.md).
- **Security fixes from two security reviews**, in the platform and in Conversational BI 0.1.3, dbt 0.1.1 and Ingestion (dlt) 0.1.1. What is still open is listed in the [security review](../security-review.md).
- **The user portal rides out a Polaris or Keycloak restart.** Sessions stay open; notebooks stop only after 90 seconds of outage.
- **Audit logs.** The Bridge logs every automation principal it creates or revokes and every token it issues; `docker compose logs bridge` shows them (on Kubernetes `kubectl -n iceberg logs deploy/bridge`).

See the [changelog](../changelog.md) for details.

## Install this version

Linux / macOS:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.9/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.9/install.ps1 | iex
```

The installers pin the installation bundle and all application images to `0.9.9`, Conversational
BI to `0.1.3`, the dbt extension to `0.1.1` and Ingestion (dlt) to `0.1.1`. In a terminal the
installer asks which extensions to add; `ICEBERG_EXTENSIONS=conversationalbi,dbt,ingestion` adds
all three without questions. OpenMetadata has its own installer:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/openmetadata-v0.1.1/install.sh | sh
```

The installers need Docker with Compose. The release workflow builds images for Linux AMD64 and ARM64.

On Kubernetes, install the charts of this version:

```bash
helm install iceberg oci://ghcr.io/sanderdw/charts/iceberg-data-platform --version 0.9.9 -n iceberg \
  --create-namespace --set baseDomain=data.example.com --set tls.clusterIssuer=letsencrypt-prod --wait --timeout 15m
```

The extension charts are `iceberg-conversationalbi` 0.1.3, `iceberg-dbt` 0.1.1 and `iceberg-ingestion` 0.1.1;
see [add extensions](../install-kubernetes.md#add-extensions).
