# Iceberg Data Platform 0.9.10

Release date: 2026-10-27

## Changes

- **Example notebook: how Apache Iceberg works.** Notebook 11 builds a table with DuckDB, shows its snapshots and files, deletes a row and then removes it for good.
- **Documentation by purpose:** tutorials, how-to guides, reference and concepts, with new pages such as [Run a class](../run-a-class.md) and [Build a semantic model](../build-a-semantic-model.md).
- **DuckDB 2.0** in notebooks, table previews, Conversational BI and dbt.
- **Security:** eMudhra emSign certificates are no longer trusted, after that authority's security incident.

See the [changelog](../changelog.md) for details.

## Install this version

Linux / macOS:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.10/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/sanderdw/iceberg-data-platform/releases/download/v0.9.10/install.ps1 | iex
```

The installers pin the installation bundle and all application images to `0.9.10`, Conversational
BI to `0.1.4`, the dbt extension to `0.1.2` and Ingestion (dlt) to `0.1.2`. In a terminal the
installer asks which extensions to add; `ICEBERG_EXTENSIONS=conversationalbi,dbt,ingestion` adds
all three without questions. OpenMetadata has its own installer:

```bash
curl -fsSL https://github.com/sanderdw/iceberg-data-platform/releases/download/openmetadata-v0.1.2/install.sh | sh
```

The installers need Docker with Compose. The release workflow builds images for Linux AMD64 and ARM64.

On Kubernetes, install the charts of this version:

```bash
helm install iceberg oci://ghcr.io/sanderdw/charts/iceberg-data-platform --version 0.9.10 -n iceberg \
  --create-namespace --set baseDomain=data.example.com --set tls.clusterIssuer=letsencrypt-prod --wait --timeout 15m
```

The extension charts are `iceberg-conversationalbi` 0.1.4, `iceberg-dbt` 0.1.2 and `iceberg-ingestion` 0.1.2;
see [add extensions](../install-kubernetes.md#add-extensions).
